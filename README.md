# SubletShield — Wizard

Dit is een kant-en-klaar React-project (gebouwd met Vite) rond de SubletShield-wizard.

## Lokaal testen (optioneel)
```
npm install
npm run dev
```

## Online zetten
Zie de uitleg van Claude in de chat, of kort samengevat:
1. Zet deze map in een GitHub-repository.
2. Ga naar vercel.com of netlify.com, kies "Import project" / "Add new site" en koppel de repository.
3. Build command: `npm run build` — Output map: `dist`
4. Klaar — je krijgt een gratis, deelbare link.
